# Adrien Caron — CV interactif

Site CV statique en HTML/CSS/JavaScript, sans framework ni dépendance.

## Structure
- `index.html` : contenu et structure
- `styles.css` : design responsive
- `script.js` : menu mobile + parcours recruteur interactif
- `Adrien_Caron_CV.pdf` : CV PDF utilisé par les boutons de téléchargement

## Tester en local
Ouvrir `index.html` dans un navigateur.

Pour un serveur local :
- Python : `python -m http.server 8000`
- puis ouvrir `http://localhost:8000`

## Mise en ligne
Le site peut être hébergé sur n'importe quel hébergeur de site statique (par exemple GitHub Pages, Netlify, Vercel ou un hébergement web classique).

## À personnaliser avant publication
- Ajouter une vraie photo professionnelle si souhaité.
- Ajouter l'URL de ton LinkedIn.
- Remplacer éventuellement l'adresse e-mail affichée si elle change.
- Vérifier les intitulés/dates d'expérience avant publication.
- Ajouter un nom de domaine si souhaité.

## LinkedIn

## Photo
Le bloc `PHOTO` est volontairement laissé comme emplacement. Tu pourras remplacer `.photo-placeholder` dans `index.html` par une balise `<img>` lorsque tu auras choisi ta photo.
